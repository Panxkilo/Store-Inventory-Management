# Store Inventory & Order Management

Sistema de inventario y gestión de órdenes desarrollado en **Java** con programación orientada a objetos.
Lo hice como evaluación técnica de ingreso a un programa de formación, con entrega por Pull Request y defensa posterior de la solución.

## Qué hace
- Modela productos y el stock de una tienda.
- Procesa órdenes de compra y aplica **descuentos por tramos** según el monto.
- Guarda los datos mediante **serialización**, así que el inventario se conserva entre ejecuciones.

## Tecnologías
- Java (POO)
- Maven

## Cómo ejecutarlo
1. Cloná el repositorio:
   `git clone https://github.com/Panxkilo/Store-Inventory-Management.git`
2. Compilá con Maven:
   `mvn compile`
3. Ejecutá la clase principal del paquete `com.store` desde tu IDE.
